# NOVA AI 2.0 — Growth, in motion

A responsive futuristic HTML/CSS/JavaScript prototype with animated particles, orbiting 3D-style orb, glassmorphism panels and a small-business content studio.

## Run
1. Open `index.html` in VS Code.
2. Use Live Server for the best experience.
3. Demo mode works immediately.
4. Click **Load local model** to try optional browser inference via Transformers.js and `onnx-community/Qwen2.5-0.5B-Instruct`. First run needs internet to download the library and model files, and enough device memory.

## Honest project notes
- Demo templates are not AI inference.
- The optional open-weight model runs in the browser when it successfully loads.
- The page uses Google Fonts and a CDN, so the initial page/model setup is not fully offline.
- Check current model card and license before commercial use. Validate outputs with real users before making claims about quality or business results.
